# Fitness Step Goal Tracker

A simple console-based **Fitness Step Goal Tracker** developed in C++ using basic programming concepts and control statements.

## 📌 About the Project

The Fitness Step Goal Tracker allows users to set a daily step goal and track their steps for multiple days.

The program calculates total steps, average steps, goal achievement, and the best day.

## ✨ Features

- Set a daily step goal
- Track steps for multiple days
- Check whether the daily goal was achieved
- Calculate total steps
- Calculate average daily steps
- Count the number of days the goal was achieved
- Find the best step-count day
- Handle invalid input

## 🛠️ Concepts Used

- C++ Basics
- Variables
- Data Types
- `cin` and `cout`
- `if-else`
- `for` loop
- `continue`
- Arithmetic Operators
- Type Casting
- Basic Input Validation
